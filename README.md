# Student Study Planner

Student Study Planner is a simple web application designed to help students organize and keep track of their school tasks.

## Features

- Add new study tasks
- Edit and delete tasks
- Mark tasks as completed or pending
- Set due dates
- Set task priority
- Filter tasks by status
- Sort tasks by due date or priority
- Track overall progress
- View task deadlines on a calendar
- Light and dark mode
- Local Storage to save user data
- Responsive design for desktop and mobile devices

## Client Feedback and Design Changes

After reviewing the original mockup, the client requested that the application be kept as simple and easy to use as possible.
Based on this feedback, I made some changes between the original mockup and the final version of the application.
The original design included a sidebar on the left side with several navigation options. I decided to remove this sidebar to simplify the interface and avoid unnecessary sections.
Instead, I created a small header with three essential navigation options: Dashboard, All Tasks, and Calendar. These links take the user directly to the corresponding section of the same page.
The final application was designed as a single-page experience so students can quickly add tasks, check their progress, manage their assignments, and view their calendar without navigating through multiple pages.
I also tried to keep the visual design simple, clear, and easy to understand so that the application can be used comfortably by different students.
These changes were made based on the client's feedback while keeping the main functionality and requirements of the original project.
